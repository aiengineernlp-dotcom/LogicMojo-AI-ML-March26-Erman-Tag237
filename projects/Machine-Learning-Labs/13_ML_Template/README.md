# Machine Learning Template

This folder contains a universal Machine Learning workflow that can be reused for almost every ML algorithm.

The goal is not to memorize every algorithm independently, but to understand the common pipeline used by Data Scientists.

---

## Universal Machine Learning Workflow

1. Import Libraries
2. Load Dataset
3. Explore Dataset (EDA)
4. Select Features (X) and Target (y)
5. Train/Test Split
6. Data Preprocessing
7. Select Model
8. Train Model
9. Make Predictions
10. Evaluate Model
11. Interpret Results
12. Visualize Results

---

## Algorithms that follow this workflow

- Linear Regression
- Multiple Linear Regression
- Logistic Regression
- KNN
- Decision Tree
- Random Forest
- SVM
- Naive Bayes
- K-Means
- PCA
- XGBoost
- Neural Networks

Only a few steps change depending on the algorithm:

- preprocessing
- model
- hyperparameters
- evaluation metrics

Everything else is almost identical.
